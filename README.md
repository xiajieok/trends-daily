# trends-daily

每日技术趋势聚合：Hacker News Top/Ask/Show + GitHub Trending

## 功能

- 📊 HN 热门 Top 20
- 💬 Ask HN — 大家在问
- 🎨 Show HN — 大家在秀
- 📦 GitHub 热门项目

## 预览

https://econow.cn/trends-daily/

## 技术栈

- Python（数据抓取 + HTML生成）
- Cloudflare Pages（免费部署）

## 本地运行

```bash
pip install requests
python fetch_trends.py
```

## 数据来源

- Hacker News API (Firebase)
- GitHub Trending
